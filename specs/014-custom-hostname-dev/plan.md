# Implementation Plan: Custom Hostname Dev Access

**Branch**: `014-custom-hostname-dev` | **Date**: 2026-03-25 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `/specs/014-custom-hostname-dev/spec.md`

## Summary

Allow the dev servers to be accessed via both `localhost:{PORT}` and `localhost.ministrosfc.com:{PORT}`. This requires two environment-variable-only changes: (1) bind the Nuxt frontend dev server to `0.0.0.0` via `NUXT_HOST`, and (2) add `http://localhost.ministrosfc.com:5103` to the backend CORS allowlist via `CORS_ORIGINS`. No source-code logic changes are needed — the existing `server.ts` already supports comma-separated origins, and the `nuxt.config.ts` will read `NUXT_HOST` via `devServer.host`. The feature also corrects a discrepancy in `.env.example` (singular `CORS_ORIGIN` → plural `CORS_ORIGINS`).
